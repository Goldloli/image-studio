# workspace-canvas Specification

## Purpose

为 Image Studio 提供离线示例、持久化草稿与真实图片结果的画板交互；保持各类内容的身份、编辑目标和来源明确，使已有项目重开后仍可查看与操作，避免把示例或界面进度误认为正式生成资产。

## Requirements

### Requirement: 离线示例与空白草稿

应用 SHALL 内嵌 3 张有来源记录的原创示例图片与对应提示词。全新本地库首次打开 SHALL 选择一个空会话及其待发送草稿，显示标题、示例入口与明确说明，不把示例图当成会话生成结果。每张示例 SHALL 提供查看图片和使用提示词两个可区分的操作。查看 SHALL 只切换图片查看状态，composer 保持绑定明确当前会话；使用提示词 SHALL 仅修改该会话的待发送草稿。已有项目重开 SHALL 恢复已保存会话与输入；新建会话 SHALL 不覆盖已有会话。示例可通过明确入口到达，不依赖以图片充当会话的作品条。

#### Scenario: 无网络首次查看
- **WHEN** 用户在断网、无模型、无用户资产时打开创作页
- **THEN** 空会话及示例入口正常显示，示例不需要下载，不计为用户资产、已发送消息或生成任务

#### Scenario: 查看和使用提示词分离
- **WHEN** 用户查看示例大图，再选择使用示例提示词
- **THEN** 前者不改变会话输入，后者仅修改明确当前会话的待发送文字并可撤销，不隐式发送或生成图片

#### Scenario: 新建与切换草稿
- **WHEN** 用户编辑会话 A 输入后新建 B，再返回 A
- **THEN** B 是独立空历史，A 已保存的输入、参数和历史仍存在，切换不会把示例或另一会话内容灌入 A

#### Scenario: 示例查看期间编辑的目标明确
- **WHEN** 用户从 A 查看示例，并编辑文字或使用示例提示词后返回
- **THEN** composer 始终明确标识 A，A 保留操作，B 不变，示例素材本身不被修改

#### Scenario: 已有项目恢复不被示例替换
- **WHEN** 本地库已有会话、已保存输入或生成结果，用户重开应用
- **THEN** 恢复对应数据，三个示例仍可达但不覆盖用户内容或冒充生成结果

### Requirement: 示例画板变换

示例画板 SHALL 以保持宽高比的 contain-fit 显示图片，默认不超过原始分辨率；提供 25%–400% 相对适配尺寸缩放、每次 25% 步进、拖动平移、左右 90° 旋转和重置。工具条 SHALL 位于画板左侧，图片内容 SHALL 被限制在画板裁剪区域，摘要与示例标识 SHALL 不随图片变换。缩放边界 SHALL 禁用对应操作；切换图片 SHALL 恢复其初始适配变换。

#### Scenario: 缩放和重置
- **WHEN** 用户连续缩小到下界、放大到上界并点击重置
- **THEN** 缩放保持在 25%–400%，边界按钮禁用，重置后图片回到完整适配、无平移和无旋转状态

#### Scenario: 拖动旋转不影响编辑
- **WHEN** 用户在示例画板中平移并旋转图片，再点击提示词输入框编辑
- **THEN** 图片变换不覆盖提示词，不超出画板遮挡导航或输入，指针操作不误触其他工具

#### Scenario: 切换不同构图图片
- **WHEN** 用户从示例入口或图片查看器切换不同宽高比示例
- **THEN** 图片不拉伸，工具与示例标识可见，新图片使用初始适配变换而非上一张的偏移

### Requirement: 示例展示不改变执行和资产状态

示例浏览和图片变换 SHALL 只改变查看状态，文字模板应用 SHALL 仅修改明确当前会话的待发送草稿并可进入草稿保存流程；这些动作 MUST 不创建对话 Turn、图片 Asset、Job、Attempt 或 RunManifest，不因示例创建新项目，不写用户图片目录，也不显示未经执行的生成成功或可继续推理状态。示例来源说明 SHALL 可从关于页找到；示例资源异常 SHALL 局部报错并提供返回当前会话入口，不阻塞整个应用。

#### Scenario: 画布操作后查看状态
- **WHEN** 用户浏览所有示例、修改提示词并进行多次图片变换
- **THEN** 这些动作不改变真实模型或任务计数，除明确草稿保存外没有执行或正式图片资产副作用

#### Scenario: 示例不可读取
- **WHEN** 示例解码或纹理加载失败
- **THEN** 当前图片区域显示可理解错误，导航和草稿编辑继续可用，用户可返回当前会话并继续编辑原输入

### Requirement: 跨平台模型提示按当前平台解析

Composer SHALL 仅在会话/草稿保存的模型 id（文本模型或源图工具模型）不属于当前平台支持的模型集合时显示跨平台提示；提示文案 SHALL 指向当前平台对应的型号（文本型号族或具体工具名），并要求用户核对画幅/源图与参数；当该模型在当前平台存在但只是未安装/未就绪时，SHALL 只显示"未就绪"，不得显示"当前 Windows 未接入"。

#### Scenario: Windows 原生模型
- **WHEN** Windows 用户选择 Klein / Qwen / MOSS / Z-Image 或 BiRefNet / Real-ESRGAN 的 Windows 模型 id（无论是否已安装）
- **THEN** 不显示跨平台提示；未安装时显示"未就绪"

#### Scenario: 旧 macOS 模型选择
- **WHEN** Windows 用户打开或编辑保存了 macOS 模型 id 的会话/草稿
- **THEN** 显示跨平台提示，文本模型说明需选择对应的 Windows 型号族（Z-Image / Klein / Qwen / MOSS）并核对画幅与参数；工具模型说明需选择对应的 Windows BiRefNet 去背景 / Real-ESRGAN 放大 型号并核对源图

#### Scenario: macOS 打开 Windows 会话
- **WHEN** macOS 用户打开保存了 Windows 模型 id 的会话/草稿
- **THEN** 显示对应提示，文本模型说明该选择来自 Windows 端、需选择 macOS 对应型号；工具模型同样说明对应的 macOS 工具型号，而不是只显示"未就绪"
