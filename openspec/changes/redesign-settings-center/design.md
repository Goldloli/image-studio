# Design

## Context

动机与行为契约见 [proposal.md](proposal.md) 和 [specs/application-settings/spec.md](specs/application-settings/spec.md)。

当前设置页位于主窗口 `main-surface` 内，由 `SettingsPage.tsx` 维护分类、偏好快照、创作默认值和宿主事实。现有视觉由 `model-settings.css` 中的扁平分组、外框网格和大号主题卡组成；信息虽然齐全，但每个控件各自成框，页面更像表单清单，而不是一个有明确导航和层级的偏好中心。

用户指定 bilidown 为结构参考：

- [bilidown 通用设置](references/reference-bilidown-general.png)
- [bilidown 界面设置](references/reference-bilidown-interface.png)
- [ASRbox 设置](references/reference-asrbox-settings.png)
- [当前 Image Studio 设置](references/before-image-studio-settings.png)

bilidown 参考的关键特征是独立感强的双面板结构、分类栏满色选中态、内容区圆角分组卡、行式控件和紧凑信息密度；ASRbox 参考用于补充本地路径、运行状态和事实型信息的分组方式。

## Goals / Non-Goals

**Goals**

- 保留 Image Studio 的单一主窗口与现有导航，不引入跨窗口状态同步。
- 让设置页具备 bilidown 式的视觉秩序：分类导航、内容面板、分区卡片、行式控件、单一状态头。
- 重排现有五类设置，让每个分类既能快速浏览，也能在一屏内完成主要调整。
- 增加可持久化强调色，使界面个性与 bilidown 参考中的关键视觉特征一致。
- 在 1280×800 与 960×640 逻辑窗口保持可扫描、可滚动、键盘可达。

**Non-Goals**

- 不新增独立原生设置窗口或第二个 WebView。
- 不改写模型安装、生成、存储清理、更新检查或在线服务边界。
- 不新增语言切换、快捷键自定义、托盘行为、自动更新或数据迁移等产品能力。
- 不把 ASRbox 的顶部分类页签直接复制；Image Studio 坚持左侧分类加右侧内容的偏好式结构。

## Decisions

### 1. 在现有主窗口内重建设置中心

在主窗口 `main-surface` 内增加一层设置专用容器：

| 层级 | 规格 |
| --- | --- |
| 外层 | 12px 内边距与中性 `chrome` 背景，让双面板悬浮于主工作区 |
| 分类栏 | 200px 左右圆角面板；图标 + 中文标签；选中项使用强调色实底与反色文字 |
| 内容面板 | 圆角面板，顶部固定分类标题与保存状态，内部独立滚动 |
| 内容宽度 | 约 680–760px，居中，避免控件跨过过长阅读线 |

保留主窗口左侧全局图标栏。设置按钮仍进入 `settings` 页面，关于按钮仍以 `about` 分类进入。这样不会为独立设置窗口引入两个 WebView 的状态、保存队列、主题同步和关闭确认问题。

### 2. 采用分区卡和行式控件，不再为每个字段单独套卡

新增三个只用于设置页的视觉结构，不建立跨页面万能组件：

| 结构 | 用途 |
| --- | --- |
| 设置分区 | 标题、必要时一句作用范围说明、一个连续边界的卡片容器 |
| 设置行 | 左标签/当前值，右侧分段控件、开关、下拉或输入；行间只画分隔线 |
| 事实行 | 左标签，右侧等宽数值或路径；用于存储和运行环境 |

主要控件高度控制在 28–34px，行高 44–54px。主题选择不再使用三张大卡，而是行内三档分段控件；强调色使用一排色点和自定义取色器；开关行不再层叠外层边框。

### 3. 五类页面重新组织

**通用与外观**

1. `外观` 分区：主题模式、强调色、字号、密度。
2. `交互` 分区：减弱动效、折叠会话侧栏。
3. 页面顶部只显示一个“保存中 / 已保存 / 保存失败”状态。

**创作默认值**

1. `新会话默认` 分区：模型、画幅、数量、种子使用连续行式表单。
2. 模型行右侧直接显示“可执行 / 未安装 / 不满足硬件”等真实状态。
3. 底部保留保存、放弃和恢复默认动作，但不常驻“表单与保存值一致”的提示。

**存储**

1. 顶部摘要卡显示应用数据总占用、共同可用空间或“空间未知”。
2. `存储位置` 分区逐行显示数据、模型、运行时、缓存、图片和日志，每行带目录与定位按钮。
3. 全局可用空间只出现一次；不同卷的真实可用空间不同时，回退为逐行显示。

**运行环境**

1. 顶部 `设备与平台` 分组使用事实行与状态徽标表达平台、运行时、设备事实和当前摘要。
2. `模型运行组合` 使用紧凑列表表达模型、运行时锁、模型/环境/设备/硬件门槛；异常行用固定语义色突出。
3. 继续只读取宿主事实，不启动探针或展示性能排名。

**关于**

1. 品牌摘要使用 Logo、版本徽标、本地处理说明和已接入能力。
2. `模型、字体与内容许可` 保持可展开，来源与技术证据继续可核对。
3. 自动更新、在线服务、存储迁移边界使用状态徽标而非空按钮。

### 4. 强调色进入版本化应用偏好

在 `AppearancePreferences` 中增加：

```ts
type AppearancePreferences = {
  theme: ThemeMode;
  accentColor: string; // canonical #RRGGBB
  fontScale: FontScale;
  density: Density;
  reducedMotion: boolean;
  sidebarCollapsed: boolean;
};
```

- 默认值保持现有品牌橙 `#D7641F`。
- 预设建议为橙、珊瑚、玫红、蓝、紫、石墨；不把绿色设为预设或默认，沿用用户已表达的图标色彩偏好。
- ✓ 自定义颜色接受 `#RRGGBB` 或六位十六进制输入，统一规范化为大写；原生取色器与文本输入共用同一保存路径。
- 前端把颜色写入 CSS 强调 token，并为 hover/强调变体生成稳定派生色；成功、警告、错误、禁用等语义 token 不参与强调色覆盖。
- 偏好文件从 schema v1 升级到 v2。读到 v1 时保留所有旧字段，以默认橙色补充新字段并给出非阻断迁移提示；只有下一次合法保存才以原子写入升级为 v2。

### 5. 保持现有保存与切换语义

- 外观类控件沿用现有即时保存队列，设置页顶部只显示一个保存状态。
- 创作默认值继续整组校验、显式保存；切换分类时保留现有“保存并继续 / 放弃 / 取消”确认。
- 读取失败继续显示局部警告与重试；宿主不可用时，About/Storage/Runtime 仍按当前只读边界渲染。
- 强调色保存失败时保留最后一次宿主确认值，不把临时预览标记为已保存。

### 6. 960×640 与键盘约束

- 分类栏在窄窗缩至约 176px，内容面板内部滚动，分类和标题不随正文滚走。
- 存储路径、运行时锁和错误文本允许换行；右侧控件不低于 28px 命中区。
- 分类按钮使用 `aria-current` 或等价选中语义；主题、画幅、动效使用可访问的分段组；开关提供中文名称；取色器和十六进制输入分别有标签与错误状态。
- 默认焦点落在内容面板或标题，不落在分类第一项，避免打开设置即出现无意义焦点环。

## Risks / Trade-offs

- 自定义强调色可能让部分按钮对比度不足 → 预设限制为可读颜色，自定义颜色在浅色和深色主题分别校验对比，仍不改变语义色。
- 新增偏好字段可能破坏旧偏好文件读取 → v1 兼容读取、逐字段回退、下一次保存升级 v2，并用隔离旧文件测试覆盖。
- 双面板在 960×640 下压缩可用宽度 → 分类栏按窄窗缩宽，内容独立滚动，路径与状态行允许换行。
- 行式表单可能让复杂创作默认值显得拥挤 → 使用分区卡、状态徽标和明确的保存/放弃动作，不把全部输入塞入同一行。
- 参考 bilidown 不等于复制其品牌样式 → 保留 Image Studio 的橙色、圆角、字体和中性表面，只借用信息结构。
