# Windows 功能实机回归测试计划

状态：**未执行。用户确认本 change 后才可运行。**

本计划只验证 Windows 当前构建的安装、原生界面和本地管理功能。**不得下载或安装模型、启动推理 worker、创建生成任务、调用 GPU 或生成新的模型图片。** 界面截图和既有作品可保存为证据。

## 0. 前置条件

### P01 当前构建可追溯

- [ ] 记录当前提交、构建时间和安装包/可执行文件 SHA-256。
- [ ] 当前提交的 GitHub quality 与 Windows build workflow 已通过，或明确记录阻塞原因。
- [ ] 安装包来自该提交对应的成功 CI artifact，不使用未登记的本机构建替代。

### P02 机器与系统身份

- [ ] 记录 Windows 版本/build、架构、CPU、RAM、GPU/驱动、WebView2 版本和显示配置。
- [ ] 首选既有 Windows 10 22H2 / RTX 3080 Ti 12 GB / 32 GB RAM 目标机。

### P03 历史生图基线

- [ ] 记录历史 Windows 生图认证的提交、设备、证据目录、模型/运行时身份与覆盖范围。
- [ ] 审查当前提交相对基线的 diff，重点检查 worker、运行时、模型清单、协议、配方、设备门槛、安装量化、发送与恢复链。
- [ ] 将结论写为 `no execution-surface change`、`execution-surface change` 或 `ambiguous`。
- [ ] `execution-surface change` 或 `ambiguous` 时，本计划不能替代完整生图认证。

### P04 数据安全

- [ ] 使用 `--data-dir C:\ImageStudioAccept` 或可丢弃的数据根。
- [ ] 若验证升级，先复制真实 v5 数据库、作品、导入源图和相关索引文件；不得直接操作唯一用户副本。
- [ ] 记录所有原始测试文件及外部导出副本的 SHA-256，验收后可按需要恢复。

## 1. 安装与启动

### I01 当前用户安装

- [ ] 在无 Node、Rust、开发用 Python 或完整 CUDA Toolkit 依赖假设下完成 current-user NSIS 安装。
- [ ] 从安装目录启动，主窗口可见，首次启动不下载模型、不准备私人运行时、不安装 GPU 驱动。
- [ ] 若 WebView2 缺失，安装器使用包内离线依赖；无法继续时给出可操作错误。

### I02 安装身份与日志

- [ ] 校验安装包哈希与 CI `internal-package.json` 一致。
- [ ] 检查应用版本、安装目标 `x86_64-pc-windows-msvc`、图标和许可证资源。
- [ ] 正常启动后存在 `<data>/logs/app.log`，无仅依赖 stderr 的失败路径。

### I03 数据根所有权

- [ ] 同一数据根第二次启动被明确拒绝，不修改数据库或启动计算。
- [ ] 使用另一个短数据根可同时启动，两个 WebView2 profile 和数据目录互不干扰。

## 2. 升级与数据库

### D01 v5 到 v6 升级

- [ ] 用包含多会话、草稿、成功/失败/取消任务、普通作品和 BiRefNet 双输出的 v5 副本首次启动。
- [ ] 升级后会话、作品、导入源图、请求、计划、manifest、Asset ID、文件路径和图片字节保持不变。
- [ ] 既有会话均可见、既有作品默认未收藏、删除状态为空或默认 active。

### D02 重复启动幂等

- [ ] 关闭并再次启动，不重复迁移、不复制作品、不创建额外默认会话。

### D03 迁移失败保护

- [ ] 如可安全构造，验证不可读/不可写/升级失败不重建空库；无法构造时记录 `not_run`，不得伪造通过。

## 3. 原生工作区

### U01 单层导航与删除项

- [ ] 左侧只有创作、灵感库、模型、作品、设置及主题/关于入口；选中态正确。
- [ ] 无顶部页面页签、页签关闭按钮、“功能”页和“任务”页。
- [ ] 无“开发”按钮、开发菜单或诊断抽屉，设置中无打开抽屉的死入口。

### U02 窗口与 DPI

- [ ] 1280×800 和 960×640 下导航、会话列表、输入框、参数、模型状态和主要按钮可达。
- [ ] 检查 100%、150%、200% DPI；至少完整检查一种 DPI，其余无法切换时记录 `not_run`。
- [ ] 最小化、最大化、还原、关闭和拖动正常，拖动区不吞按钮点击。

### U03 主题与键盘

- [ ] 亮/暗主题切换后当前页面、输入、弹层、焦点和图片表面同步更新。
- [ ] Tab/Shift+Tab、Enter、Escape 可完成导航、弹层和确认框主要操作。
- [ ] hover、selected、focus、disabled 状态可辨认，图标按钮有可访问中文名称。

### U04 中文输入与草稿

- [ ] 使用真实 Windows 中文 IME 输入、确认候选、中英文混输、多行粘贴、选择和撤销。
- [ ] IME 候选确认的 Enter 不触发发送，不显示执行任务。
- [ ] 在多个会话写入不同草稿，切换页面/会话后内容各自保留；重启后已确认草稿恢复。

### U05 灵感库与关于

- [ ] 灵感库搜索、分类、筛选、排序和滚动位置可恢复。
- [ ] 案例来源、使用条件及“示例 · 非本机生成”标识可核对；不创建生成任务。
- [ ] 设置 → 关于包含灵感库来源与许可、应用版本和真实能力边界。

### U06 模型页只读投影

- [ ] 七个登记型号显示各自的安装、运行时、设备、档位、许可和可执行状态。
- [ ] 未安装型号显示真实原因和禁用入口，不自动下载、安装或切换型号。
- [ ] 已安装型号显示 `standard` 或设备实际匹配的档位；本项只读检查，不发送。

## 4. 会话管理

### C01 新建、切换与重命名

- [ ] 新建会话使用持久默认值，不继承当前会话瞬时参数，不创建 Turn/Job/Asset。
- [ ] 在多个会话保存不同输入与参数，切换和重启后正确恢复。
- [ ] 重命名提交、取消和长标题显示正常，不覆盖输入或切换错误会话。

### C02 删除非当前空闲会话

- [ ] 操作按钮在不误触会话切换的情况下可点击和键盘聚焦。
- [ ] 取消/Escape 无副作用；确认后目标从列表和分页移除，当前会话输入保持不变。
- [ ] 重启后已删除会话不复活。

### C03 删除当前和最后一个会话

- [ ] 删除当前会话后选择最近活动的未删除后继。
- [ ] 删除最后一个会话时同事务创建一个默认空会话，不产生 Turn/Job/Asset。

### C04 会话墓碑与作品保留

- [ ] 删除有测试作品的会话后，作品、收藏、原图和制作信息来源保持。
- [ ] 来源显示原会话标题及“会话已删除”，返回会话入口不可用。
- [ ] 旧保存、分页或导航响应不能复活已删除会话。

## 5. 作品管理与文件操作

### A01 查询、筛选与空态

- [ ] 核对总数、分页、日期/模型/尺寸/会话/仅收藏组合筛选。
- [ ] 区分无作品、无收藏、组合无结果和读取失败，并提供对应动作。
- [ ] 迟到查询不覆盖当前筛选、收藏或删除状态。

### A02 收藏持久化

- [ ] 收藏和取消收藏不打开预览，不误触删除；重启后状态保持。
- [ ] “仅收藏”按完整数据集查询，不只过滤当前页。

### A03 既有作品预览与导出

- [ ] 未加载模型时仍可查看历史作品和原位制作记录。
- [ ] 通过原生保存对话框导出既有 PNG；记录导出 SHA-256 与正式资产一致。
- [ ] 取消、拒绝覆盖和中文/空格路径按合同工作，原资产不被修改。

### A04 普通作品受控删除

- [ ] 取消确认无副作用。
- [ ] 确认后应用内登记原图/缓存删除，作品、收藏和计数移除；外部导出副本字节不变。
- [ ] 重启后作品不复活，原 Job/Attempt/Manifest 历史仍可查。

### A05 双输出作品删除

- [ ] 对测试 BiRefNet 作品确认 primary 与 mask 作为一组删除。
- [ ] 两个旧 Asset ID 均不可读取、导出或继续作为源图；导入源图和其他作品保持。

### A06 引用阻止与解除

- [ ] 当前草稿把测试作品作为源图时，删除被拒并给出会话与解除动作。
- [ ] 切走能力后未激活槽位仍引用时，消息包含对应能力名及解除路径。
- [ ] 按提示移除/更换源图后可删除；不要求启动活动生成任务。

### A07 只读文件删除

- [ ] 给测试资产设置只读属性后确认删除。
- [ ] 应用只处理登记测试文件，完成或显示可重试失败；不扩大权限、不删除外部文件。
- [ ] 验收后恢复测试环境属性。

### A08 文件占用失败与重试

- [ ] 用 PowerShell 或测试工具以不共享句柄占用测试资产文件。
- [ ] 删除显示“删除未完成”及原因，不虚报成功，作品不恢复为正常可用。
- [ ] 关闭句柄后重试成功；外部导出、导入原件和其他文件保持。

### A09 删除中断恢复

- [ ] 在测试库副本中制造主图已处理、最终完成状态尚未提交的中断。
- [ ] 重启只依据已确认意图恢复，不复活作品、不生成新图片；无法安全制造时记录 `not_run`。

## 6. 设置、路径与诊断

### S01 五组设置

- [ ] 通用与外观、创作默认值、存储、运行环境与诊断、关于均可打开。
- [ ] 有未保存默认值时切换分组会保存、放弃或取消，不静默丢失。
- [ ] 主题、字体、密度、减弱动效和侧栏偏好重启后恢复。

### S02 存储路径

- [ ] 显示 data/model/runtime/cache/image/log 的实际路径、占用和可选空闲容量。
- [ ] “在文件管理器中显示”只打开登记目录，不接受前端任意路径。
- [ ] 不存在自动迁移、整目录删除、任意路径输入或无效 GPU 开关。

### S03 启动失败诊断

- [ ] 使用超过 94 UTF-16 units 的数据路径启动，应用在创建下载/运行时前拒绝。
- [ ] 对应 `<data>/logs/startup-failure.log` 有原因和修复建议，原生对话框说明下一步。
- [ ] 失败不修改已有会话、作品、模型安装记录或图片。

### S04 日志与进程观察

- [ ] `app.log` 每行包含时间、级别、事件和关键字段；轮转文件不超过约定上限。
- [ ] 整个验收期间进程列表和日志不出现生成 worker/推理 worker；模型目录和 prepared 缓存无新增或改写。

## 7. 结论与证据

### E01 证据归档

- [ ] 保存逐项 `pass/fail/blocked/not_run` 表格、截图、日志、DB 查询和文件哈希。
- [ ] 记录所有失败项、复现步骤和后续 Beads。
- [ ] 记录功能回归使用的提交、安装包哈希、数据根、机器身份和历史生图基线。

### E02 结论标签

- [ ] 报告明确写出“Windows 功能回归通过/失败”。
- [ ] 单独写出“复用历史生图基线”或“生图认证未运行”。
- [ ] 不得写成七模型八能力、GPU 资源、图片质量或性能重新认证通过。

## 不在本计划范围

- 模型权重下载、运行时安装、安装期量化或联网安装链路。
- 文生图、图片编辑、去背景、放大或任何新模型输出。
- CUDA reserved、private commit、加载/生成墙钟、图片质量、取消/强杀恢复。
- 新硬件、新 Windows 版本、8 GB/12 GB 档位扩展或性能承诺。
