# Spec Delta

## ADDED Requirements

### Requirement: 作品卡片不重复提示词和状态

作品卡片 SHALL 在一个主要位置显示提示词，并在一个主要位置显示资源与操作状态。缩略图已经承担预览入口时，MUST 不再用独立“预览”文字重复同一动作；标题与副行不得重复同一提示词。

#### Scenario: 浏览网格作品
- **WHEN** 用户在网格中查看一件可用作品
- **THEN** 提示词、来源、元数据和状态各出现一次，缩略图及其可访问名称清楚表达预览动作

#### Scenario: 作品资源异常
- **WHEN** 缩略图缺失或无法解码
- **THEN** 卡片显示异常状态和恢复信息，不把正常状态的同义标签继续叠加

### Requirement: 作品预览只展示任务所需元数据

作品预览 SHALL 以图片、提示词、主要导出动作为首位。会话、型号、尺寸、种子和完成时间 SHALL 在一个信息区展示；`AssetRef`、`Job`、`Attempt` 等稳定技术身份 MUST 默认收在高级详情或可复制字段中。

#### Scenario: 打开作品预览
- **WHEN** 用户从作品列表打开预览
- **THEN** 图片与提示词可见，来源会话和时间不在顶栏与侧栏重复显示

#### Scenario: 查看技术身份
- **WHEN** 用户需要 AssetRef、Job 或 Attempt 身份
- **THEN** 相关标识可通过高级详情或复制动作获得，不长期占用普通作品信息区域
