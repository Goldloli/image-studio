# Spec Delta

## ADDED Requirements

### Requirement: 灵感库来源和数量只保留主要表达

灵感库主页面 SHALL 只保留一个主要来源说明、一个完整目录总数和一个当前结果数。分类计数、设备筛选和页面总数已经表达同一集合时，MUST 不再增加重复统计行或逐卡“上游示例”徽标。

#### Scenario: 浏览全部案例
- **WHEN** 用户未应用搜索或筛选并查看全部案例
- **THEN** 页面不在分类计数、标签和结果行中重复显示相同总数

#### Scenario: 查看来源身份
- **WHEN** 用户浏览灵感库或某张案例
- **THEN** “上游示例、非本机生成”的来源事实仍可通过一个主要说明和必要详情获知，不在每张卡片和每个元数据位置重复

### Requirement: 案例详情按任务优先级组织信息

案例详情 SHALL 优先展示大图、标题、完整提示词、复制与使用动作。分类、参考图条件、来源和模型不确定性 SHALL 分组呈现，并与列表层级的来源说明去重；必要使用限制和许可入口 MUST 仍可访问。

#### Scenario: 打开案例详情
- **WHEN** 用户从列表打开一个案例
- **THEN** 页面不同时重复显示相同分类、案例编号、上游示例徽标和来源说明

#### Scenario: 案例需要参考图
- **WHEN** 案例使用条件要求参考图或编辑能力
- **THEN** 条件与可执行动作在详情中清楚可见，模型和参数的不确定性说明收在次级说明区域

#### Scenario: 复制并填入提示词
- **WHEN** 用户复制或把完整提示词填入会话
- **THEN** 原文、复制反馈和填入动作保持可用，不额外增加重复操作说明
