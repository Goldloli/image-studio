# Spec Delta

## ADDED Requirements

### Requirement: 模型页统计和筛选不重复表达

模型页 SHALL 以侧栏筛选及其计数作为目录规模的主要入口。顶部 MUST 不再重复显示与侧栏相同的全量统计条；静态“本地模型库”标签、通用页面副标题和重复“模型”标题一并移除。读取、筛选和安装状态仍 SHALL 在其发生位置表达。

#### Scenario: 打开模型目录
- **WHEN** 用户打开模型页并看到全部、已安装、可执行和设备满足筛选
- **THEN** 这些筛选承担目录规模表达，页面顶部不再重复同一组统计

#### Scenario: 目录读取失败
- **WHEN** 模型目录无法读取
- **THEN** 页面显示错误和重试入口，不用空列表或重复统计伪装当前状态

### Requirement: 模型详情按状态、行动和证据分层

模型详情 SHALL 先显示名称、真实能力、当前阻塞或可执行状态和主要动作；固定配方、许可、来源、尺寸预算、验证设备与完整状态证据 SHALL 分组或放入可展开详情。同一许可、版本、状态或模型身份 MUST 不在常驻标签与详情字段中重复出现。

#### Scenario: 展开已就绪模型
- **WHEN** 用户展开一个当前可执行的模型
- **THEN** 首要区域显示能力和主要动作，许可、来源与同义状态不在多个行内重复

#### Scenario: 模型被设备门槛阻塞
- **WHEN** 当前设备不满足模型硬件门槛
- **THEN** 阻塞原因和禁用动作清楚可见，完整硬件证据与来源仍可展开查看

#### Scenario: 查看安装或运行事实
- **WHEN** 用户查看安装阶段、运行时或设备验证
- **THEN** 每项事实只在一个主要位置表达，其他技术身份按需展开
