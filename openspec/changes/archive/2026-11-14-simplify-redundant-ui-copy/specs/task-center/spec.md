# Spec Delta

## ADDED Requirements

### Requirement: 制作记录避免重复摘要和裸露技术身份

制作记录 SHALL 在摘要区域只展示一次请求的会话、型号、尺寸、种子、时间和可执行下一步。`Job`、`Attempt`、输出哈希、manifest 与日志 MUST 放入明确标记的高级区域；父级作品预览已经展示的同一摘要不得在记录中完整重复。

#### Scenario: 从作品预览展开制作记录
- **WHEN** 用户已在作品预览看到会话、型号、尺寸和种子后展开记录
- **THEN** 制作记录优先显示执行状态、错误或下一步，不重复同一摘要或把技术 ID 放在首屏

#### Scenario: 查看高级执行证据
- **WHEN** 用户展开完整制作记录
- **THEN** Job、Attempt、输出哈希、manifest 和日志可读取或复制，普通摘要仍保持简洁

#### Scenario: 制作记录读取失败
- **WHEN** 当前上下文的记录读取失败
- **THEN** 显示局部错误和重试动作，不要求导航到独立任务页
