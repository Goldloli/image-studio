# 界面精简与会话、作品管理

## Why

当前顶部页签与左侧导航重复，“功能”“任务”和开发面板增加了主创作流程的入口数量；会话与作品则缺少日常整理所需的删除、收藏操作。本次按用户的六项删除清单精简界面，同时补齐会话删除、作品删除与收藏筛选。

## What Changes

### 用户已明确的范围

| 类型 | 需求 | 提案中的对应行为 |
| --- | --- | --- |
| 删除 1 | 上方页签功能 | 删除整套顶部页面页签、关闭页签按钮及打开页签状态；保留原生窗口按钮和必要拖动区域，使用左侧导航切页。 |
| 删除 2 | 左下角“示例灵感” | 删除会话侧栏底部的该按钮及其占位；创作空会话中央的三张示例卡不在删除清单内，继续保留。 |
| 删除 3 | “功能”整个菜单栏 | **BREAKING** 删除左侧“功能”导航及其独立页面；已有文生图、编辑、去背景、放大通过创作页现有表单继续使用。 |
| 删除 4 | “任务”整个菜单栏 | **BREAKING** 删除左侧“任务”导航及独立任务列表、筛选与详情页面；生成状态、停止、重试和制作信息保留在会话或作品的现有上下文中。 |
| 删除 5 | 右侧“开发”功能 | 删除顶部“开发”按钮、菜单、右侧诊断抽屉及其中的启动/停止和开发窗口尺寸按钮；清除设置中打开同一抽屉的关联入口。 |
| 删除 6 | 灵感库“来源与内容许可”说明文字 | 删除该独立折叠说明区及详情中的通用许可说明段落；集中说明放在现有“设置 → 关于”许可入口。案例署名/来源链接、必要参考图使用条件和“非本机生成”标识保留。 |
| 新增 1 | 会话行删除按钮 | 每行右侧在悬停或键盘焦点进入时显示“重命名、删除”两个操作；删除前明确确认。 |
| 新增 2 | 作品删除与收藏 | 每件作品的右下角提供收藏/取消收藏、删除按钮，网格和列表均可操作；筛选区增加“收藏：全部作品 / 仅收藏”。 |

用户已进一步确认：

- **删除会话后保留已生成作品。** 被删除会话不再出现在侧栏，其未发送草稿被移除；保留作品仍可预览、导出和收藏，来源注明“会话已删除”，不重新创建原会话。
- **删除作品同时删除应用内原图。** 同次生成的配套蒙版及该作品专用缩略图/预览缓存一起清理，已导出的外部副本保持。

### 本提案待整体确认的交互与数据选择

- 会话删除和作品删除都采用有明确范围说明的确认框；收藏即时保存，无确认框。
- 目标会话仍在接收、准备、生成、取消或清理时不可删除，先由用户在原卡停止并等清理结束；其他空闲会话仍可删除。
- 删除当前会话后选中剩余会话中最近活动的一项；删除最后一个会话时原子创建并选中一个使用默认值的空会话。
- 已删除会话的作品保留原会话身份和标题来源，其会话筛选项标注“已删除”；返回该会话的动作不可用。
- 作品仍被未删除会话的待发送草稿或活动请求作为参考图使用时，阻止删除并给出关联位置。已完成的派生作品和不可变制作记录保持。
- 文件清理失败或中途退出不报告成功；保留“删除未完成”状态和重试入口，重启恢复已确认的清理操作。
- “仅收藏”与现有日期、型号、尺寸、会话条件取交集，作用于完整持久数据集，包含一致的总数与稳定分页。

## Capabilities

### New Capabilities

无；沿用已有规格边界。

### Modified Capabilities

- `desktop-workspace`：单层主导航，移除页签、功能页、任务页和开发面板，保持窗口与创作布局可操作。
- `conversation-management`：会话行双按钮、确认删除、忙碌门禁、当前/末个会话切换及保留作品。
- `asset-library`：作品收藏、收藏筛选、确认删除、来源会话已删除与页面内制作信息。
- `prompt-library`：移除灵感库通用来源/许可说明区，保持案例使用边界和来源身份。
- `feature-catalog`：退役独立功能目录界面，保留创作中的真实能力与统一执行链路。
- `task-center`：退役独立任务界面，保留原位任务控制及可读制作记录。
- `application-settings`：移除开发抽屉关联入口，保留运行环境事实与集中的许可入口。
- `generation-conversation`：移除任务页导航依赖，明确已删除作品的卡片和查看器行为。
- `project-storage`：持久删除标记、收藏元数据、受控文件清理、升级与崩溃恢复。

## Impact

- 前端涉及 `App.tsx`、`Workspace.tsx`、`AssetLibrary.tsx`、`PromptLibrary.tsx`、`SettingsPage.tsx`、现有功能/任务组件及相关样式、类型、查询状态测试。移除通往旧页面的回调，不留下制作记录按钮跳转到已删除任务页。
- 桌面宿主涉及会话、资产、源图解析、库查询及 schema 迁移边界；增加按稳定身份删除会话、设置作品收藏和删除作品的受限命令。前端不传任意文件路径。
- 保持 Job/Attempt/RunManifest、请求、来源散列和正式资产身份的历史事实；为用户可变管理状态增加独立字段，不重写原始执行 JSON。
- macOS 与 Windows 使用同一产品行为；验证覆盖 960×640、1280×800、亮暗主题、键盘操作、旧库升级和删除中断，不把文档校验当成实机验收。
