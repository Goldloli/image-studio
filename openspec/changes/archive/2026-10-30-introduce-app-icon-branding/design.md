## Context

用户提供的参考图位于本 change 的 `references/approved-black-icon-reference.png`，为 1254×1254 RGBA PNG，外围为 alpha 透明区。它采用深色圆角底板上叠放棕橙、亮橙和奶油色三张圆角图片卡的构图，具有强烈的前后层级；前景卡使用橙色太阳与双层山形。

本 change 提出时，Tauri 桌面包使用开发占位图，工作区左栏通过 `lucide-react` 的 `Image` 图标与绿色圆形背景表达品牌。用户已通过“下一步吧”“继续”确认实施；资源与品牌入口已完成接入；macOS 工具验收与用户对 Dock/应用切换器的人工核对均通过，Windows GUI 尚未实机验收。

## Goals / Non-Goals

**Goals:**

- 将用户选定的黑色图标固定为后续产品图标母版，避免继续产生无授权的新候选。
- 产出一套在小尺寸、浅色/深色桌面背景和平台图标容器中都清楚的派生图。
- 让应用图标、左栏品牌标记和关于页品牌标记共享同一图形语言，同时不改变功能图标语义。

**Non-Goals:**

- 不在本 change 中改变产品名、全局交互主色、页面布局或按钮图标。
- 不将这张 1254×1254 参考文件直接作为未经检查的唯一打包源；需要导出各平台实际尺寸并逐项校验。

## Decisions

### 1. 参考图是视觉真相，交付资产是受控派生

保留原始 PNG 和 SHA-256，不覆盖或再次生成。实现时从它生成 1024×1024 母版，再由母版生成 macOS 和 Windows 所需尺寸。界面专用版本直接从 1254×1254 原始参考中心裁切 1040×1040，再缩放至 512×512，不经过 1024 母版裁切。除非技术约束明确要求外部留白或 alpha 处理，不移动几何结构、不改层级顺序、不换配色。

`resources/brand/manifest.json` 记录原图、1024 母版、界面版及平台容器的 SHA-256，并记录 macOS iconset 各尺寸 PNG 与 Windows ICO 各尺寸 PNG 帧的 SHA-256，便于逐份复核。生成资源不等于通过平台 GUI 验收，平台状态须依据实际验收证据更新。

### 2. 图形识别顺序固定

图标必须依次读出：

1. 深石墨色大圆角方形作为稳定轮廓；
2. 后方棕橙、中央亮橙、前方奶油色三张错位卡片形成“图片集合/创作历史”；
3. 奶油色前景卡中的橙色太阳与双层山形形成“图片”语义。

在 16–32 px 尺寸，可移除最靠后的卡片或减弱阴影，但黑色底板、橙色卡片、奶油卡片、橙色太阳与山形必须保持可辨。禁止横向拉伸、改成绿色、增加文字或缩写、更换为正圆/无衬底轮廓。

### 3. 品牌图标与功能图标分工

品牌图标用于应用包、Dock/Finder、关于页和左栏最顶部的产品入口。`创作/模型/任务/设置` 导航继续使用现有线性功能图标；普通主按钮不变。这样不会让用户误以为橙色图形是某种操作。

### 4. 平台资源与安全区

macOS 首轮交付 1024 主图及生成后的 `.icns`/打包源，包含 16、32、64、128、256、512、1024 对应 1×/2× 需要；Windows 由同一母版生成 16、24、32、48、64、128、256 ICO，但在 Windows GUI 实测前保持“已生成、未实机验收”。

参考图外围透明留白属于构图的一部分，应用包母版保留该留白，不自行裁掉使其贴边。界面专用版本单独保存并记录中心裁切过程。若 macOS 图标蒙版导致轮廓明显丢失，必须同时保存原始意图和平台适配结果，不能将裁切后的结果冒充原图。

### 5. 小尺寸与主题变体

主图标保持原图的深色底板和外围 alpha 透明留白。嵌入工作区和关于页时，使用保留透明度的 512×512 中心裁切专用版本，并保持与背景至少 2 CSS px 的视觉间隔。不得为深色模式把黑色底板改成另一套颜色；既有功能图标的 hover、focus 和选中状态也不得由图标资源替代。

### 6. 可访问名称与装饰语义

左栏品牌入口的可访问名称固定为“Image Studio · 返回创作”。带可见产品名的关于页图标视为装饰图并提供空替代文本；独立展示且无相邻文字时，替代文本为“Image Studio 应用图标”。图标不参与生成、草稿、任务或能力计数。

## Risks / Trade-offs

- [导出时丢失 alpha 或填充底色会在深色界面形成方框] → 保留参考图外围的透明度，制作独立的应用包母版与界面裁切派生版，并分别验收。
- [层叠与 3D 阴影在 16/32 px 变糊] → 使用小尺寸专用简化版，但保留橙/奶油/黑的识别关系。
- [改变品牌色会让整个界面失去一致性] → 本 change 只引入图标，不改 `--accent` 和功能状态色。
- [原图来自生成工具，后续无法精确复现] → 保存原图哈希并以栅格母版为权威来源，不在没有明确授权时重绘。
- [把品牌图误当成按钮图标] → 仅允许固定品牌位置使用，导航和操作继续使用 Lucide 语义图标。

## Migration Plan

1. 校验参考图和哈希，建立 1024 原始母版及小尺寸派生图。
2. 替换 Tauri 打包图标，并同时保留旧图直到新包通过启动、Finder、Dock 和关于页检查。
3. 将左栏和关于页品牌标记切换到新资源；失败时只回滚品牌资源，不影响会话与生成数据。
4. Windows ICO 可提前生成，但本 change 的验收只对 macOS 实机有效。

## Open Questions

无当前范围问题。正式图标是否还需等待 macOS 26 的系统 Icon Composer 专用图层，属于后续平台兼容选择；本 change 先锁定用户确认的静态视觉版本。
