## Context

用户已于 2026-10-29 确认实施 Cherry 风格工作区，随后明确要求改用 Rust core + Tauri 2 + React。此次更新替代先前 egui 设计，视觉与功能仍按已确认 proposal 与两份 delta。调研来源见 ../../../../doc/cherry-studio-ui-research.md。

## Goals / Non-Goals

目标是用 Web 界面实现接近 Cherry 绘图页的原生桌面体验，Rust 继续拥有核心契约、路径和后台诊断。保留离线启动、真实模型数0、中文输入、无推理禁用生成。本轮不实现模型后端、外部图片导入、数据库、图层/蒙版、导出、跨重启恢复或 Cherry 的聊天/供应商功能。

## Decisions

### 1. 分离原生宿主与界面

apps/desktop 作为现有 Cargo workspace 的 Tauri 2 包，保留程序名 image-studio-desktop；移除未交付的 egui UI 及其依赖。studio-core、worker-protocol、diagnostic-worker 及现有 supervisor/路径适配器继续使用。apps/frontend 使用 React、TypeScript、Vite，开发期可独立浏览器预览，明确标注浏览器预览状态；真实能力由 Tauri IPC 返回，不由前端伪造已支持模型或诊断成功。

依赖使用实际可获得的稳定版本并保留 Cargo.lock/package-lock.json。frontendDist 指向本地构建的 dist，最终 Rust 包内嵌前端、字体、图片，不依赖开发服务器、CDN、遥测或在线字体。启动顺序为 npm ci/build，再 cargo build；运行脚本和干净源码检查同步更新。

### 2. 有界 IPC

只暴露工作区只读状态与诊断开启/启动/停止/快照命令，命令接收定义好的模式枚举。前端不能提供任意可执行文件、Shell 命令、工作目录或文件路径。诊断 worker 位置与数据根仍来自受控宿主配置。诊断控制器继续后台监督、合并高频状态，JS 仅拉取有限当前快照，不传无限日志流。

正常启动无worker。诊断UI仅开发入口显式开启，生产界面不显示开发按钮。退出清理后台进程。CSP 限制本地资源和 Tauri IPC；不安装 fs、shell、http 等通用权限插件，窗口 capability 仅满足原生拖动等必要操作。React 渲染提示词为文本，不使用 dangerouslySetInnerHTML。

### 3. Cherry 外壳与主题

逻辑 CSS px 作为视觉单位：顶部44、标签高30/圆角10、一级导航宽50/按钮36/图标18、作品条宽68/缩略图44/圆角12/gap8；外壳右/下留6、圆角12、细边框0.5。主体为图标导航 + 竖作品条 + 大画板 + 底部居中 composer，最大宽1024/圆角20。取消旧大品牌header、宽提示词左栏和全局状态底栏，无常驻右参数栏。

macOS 采用 Tauri overlay 标题区，保留原生红黄绿，左侧至少90px安全区，空白处用明确拖窗区域，按钮不参与拖窗。Windows 保留原生标题栏；本轮不宣称 Windows 图形实机验收。

采用浅/深 CSS 语义 token 和上游非透明颜色分支，默认浅色，主色 #00b96b；表面与选中态为中性灰，细边框，克制阴影。标签12、辅助12、正文/提示词14、标题18–24。系统 UI 字体优先，内嵌 Noto CJK 兜底。图标用一致线性集合，按钮有名称/tooltip/hover/focus/disabled；默认无装饰动画，遵循 reduced-motion。

### 4. React 会话状态与输入

页面为创作、模型、任务、设置。创作标签不可关闭，其他页面至多一个标签；关闭当前次要页回创作。主题、页面、弹层、草稿列表、活动草稿和画板示例选择为会话内状态，不写 localStorage/数据库。

每份草稿使用独立稳定ID、名称、提示词、参数和输入框折叠状态。示例只切换画板，composer绑定最近活动草稿并明确显示名称；新建不覆盖旧草稿。示例的“使用提示词”只替换明确活动草稿，一次撤销恢复替换前文本；撤销历史按草稿隔离，中文组合期间不拦截快捷键，不在组合中更新/重挂 textarea。导航、主题和尺寸变化不丢已确认文本，后台状态不改变焦点。

composer默认展开；展开总高在正常窗口不超过220、小窗口不超过176，内部滚动，收起保留摘要与展开按钮，画板至少240高。模型空态popup可进入模型页；草稿参数向上打开，最大宽300、可滚动、不越视口。画幅 1:1/4:3/3:4/16:9/9:16，数量整数1–4，种子空或u32；明确“仅演示，未提交”。生成全路径禁用，不创建core对象。Escape只关闭当前弹层。

### 5. 示例与画板

3张原创风景/静物/插画资源在开发期准备，记录文件哈希、尺寸与来源，不使用Cherry品牌图。静态资源随应用内嵌；标注“示例·非本机生成”，不记为用户资产/任务。首次选空白草稿，展示示例卡；查看示例和使用文字是独立行为。

画板contain-fit保持宽高比、默认不超过原图；相对适配尺寸缩放25%–400%、步长25%，拖动平移、左右90°旋转、重置，切图重置。图片transform置于独立裁剪容器；工具、摘要、示例标识不随之移动。滚轮只在画板消费，textarea/弹层内部滚动不被劫持。失效资源局部报错，可回草稿。

### 6. 配套页面与验证

模型与任务页显示真实0空态。设置包含外观、工作区说明、关于和示例来源，主题切换真实发生。诊断面板保留显式开发入口和“通信诊断，不执行图片生成”。

最小960×640、默认1280×800逻辑窗口；缩略条与主导航保留，次要说明截断/折叠，弹层内部滚动。视觉矩阵包含空白首屏、示例大图/输入展开、输入收起、参数、模型空态、设置，浅深与两窗口；关键创作视图另检查1×/2×缩放。记录截图和与源参考的已知差异，不虚构像素一致率。

验证前端构建/类型、必要的草稿撤销和参数/变换边界测试；Rust fmt/clippy/test/build；原生 CUA 检查导航、窗口控制、中文IME、多行粘贴、复制撤销、弹层、主题、缩略切换、画布操作及诊断flood/hang。断网条件下确认前端真实加载、示例可用而非只观测进程存活。

## Risks / Trade-offs

WebView的字形和原生透明效果与Cherry可能不同，以固定尺寸/语义色对照并记录。前端构建成为Rust构建前置，使用明确脚本和锁文件保证可重复。IPC范围扩大风险通过最少命令、无通用文件/Shell插件和CSP控制。移除egui不改Rust核心/协议契约，worker回归继续运行。

## Migration Plan

按用户指示更新此设计后实施Tauri宿主、React界面和资源，完成原生回归再归档。没有用户数据库或文件迁移，不提交或推送。旧egui未交付UI源移除，文档与检查脚本同步更新，不能让两套入口并存且指向不同体验。
