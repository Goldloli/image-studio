## Purpose

把七个型号与八项能力完整投影到 Windows 原生界面，并展示硬件门槛与许可。

## ADDED Requirements

### Requirement: Windows 功能页/模型页投影七个型号与八项能力

Windows 功能页 SHALL 只把已接入且依赖真实的能力显示为可开始；模型页 SHALL 显示七个型号的接入、安装、运行时、设备与可执行状态，以及硬件门槛和许可；设置页 SHALL 显示 v1/v2 运行时与探测结果。

#### Scenario: 功能入口
- **WHEN** 用户浏览功能页
- **THEN** 文生图、图片编辑、去背景、放大等能力按型号真实状态展示，不创建无后端支撑的假任务

#### Scenario: 硬件或安装不满足
- **WHEN** 型号未安装、运行时不就绪或设备低于门槛
- **THEN** 界面显示可操作原因并禁用生成入口，不静默失败、不自动切换到其他型号
