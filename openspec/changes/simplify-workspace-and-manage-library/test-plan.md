# Test Plan

本计划用于用户确认后的实施验收。**目前所有功能测试均未运行，不能以提案校验替代功能通过。**

使用隔离数据根和可丢弃的旧库副本；文件删除测试不得使用用户原始作品库。每条执行时记录提交、平台、数据根、结果、失败原因及证据路径。Rust/前端 fixture 用于状态与故障注入，原生 UI 和真实模型用于跨模块验收，两者分别记录。

## 界面精简

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| U01 | 依次打开所有保留页面 | 顶部无任何页面页签或关闭按钮；左侧创作、灵感库、模型、作品、设置切换与选中一致。 |
| U02 | 检查功能和任务入口、旧导航目标 | 两个导航和独立页面均不存在；旧目标安全回退，四类创作表单仍可达。 |
| U03 | 开发/正式构建及预览检查 | 顶部无开发按钮，右侧无诊断抽屉；设置无开启抽屉的死按钮，运行环境信息仍可读。 |
| U04 | 打开空会话和示例 | 侧栏底部无“示例灵感”及专用空白，中央三卡仍可查看/填词，不计入作品。 |
| U05 | 打开灵感主页面、详情与关于许可入口 | 独立“来源与内容许可”区和详情通用许可段落消失；来源链接、必要使用条件、非本机标识及集中许可来源仍可核对。 |
| U06 | 两平台、两目标窗口、亮暗主题、1×/2× | 原生窗口按钮与拖动正常，无页签/开发栏残留占位，输入与导航不被遮挡，键盘可完成主要操作。 |
| U07 | 作品/会话查看制作记录再关闭 | 原位显示可读摘要和高级信息，关闭恢复原上下文，不打开任务页或页签，错误可局部重试。 |

## 会话管理

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| C01 | 悬停或键盘聚焦当前/非当前/长标题行 | 每行重命名和删除都可发现、可命中且不误切会话，原重命名提交/取消可用。 |
| C02 | 打开删除确认后取消/Escape | 绑定正确会话、范围说明完整；输入、作品、收藏和选择不变，焦点返回。 |
| C03 | 删除非当前空闲会话 | 当前会话输入、参数、撤销和阅读位置不变；删除项从列表与分页排除，重启不复活。 |
| C04 | 删除当前及最后一个会话 | 从完整集合选择最近活动后继；最后一项只创建一个使用持久默认值的空会话，无 Turn/Job/Asset 副作用。 |
| C05 | 在 Pending、预检、生成、取消、清理阶段删除目标 | 宿主均拒绝且不隐式取消；另一空闲会话仍可删除。 |
| C06 | 删除事务失败、旧版本确认、响应丢失和请求重放 | 失败不半删除；草稿变化需刷新确认，重复请求不重复建空会话，迟到保存/重命名/分页/导航不能复活目标。 |
| C07 | 删除有普通和收藏作品的会话 | 作品、收藏、原图/蒙版与制作信息保留；原标题及已删除标记可见，原会话筛选仍可用，返回会话不可用。 |

## 作品管理与完整查询

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| A01 | 网格/列表右下角操作、键盘操作 | 收藏、删除有独立名称和焦点，不触发预览；窄窗按钮不被元数据遮盖。 |
| A02 | 收藏、取消、重放、快速操作并重启 | 宿主持久值正确，失败显示未保存且不保留虚假值；时间、图片和灵感收藏不变。 |
| A03 | 多于一页的数据中只收藏较早作品 | 仅收藏返回该完整集合和正确总数，不能只过滤前端已加载页；分页无重复或跳项。 |
| A04 | 收藏叠加日期、型号、尺寸、会话 | 不同条件取交集；清除筛选恢复全部，未收藏新作品不进入仅收藏。 |
| A05 | 仅收藏下取消最后收藏/查询失败 | 正确区分尚无收藏、组合无结果、尚无作品和读取失败，提供相应清除/重试入口。 |
| A06 | 删除确认取消；确认删除普通作品 | 取消不改变文件；成功后登记原图与专用缓存不存在，作品/收藏/分组计数一致排除，外部导出副本散列不变。 |
| A07 | 删除去背景作品 | primary 与 mask 均删除，输入原件及独立派生作品保持；旧 primary/mask ID 不能预览、导出或用作源图。 |
| A08 | 草稿/活动请求引用该作品 | 检查所有能力草稿和活动快照，拒绝删除并提供关联位置；解除后可删，历史来源散列不改写。 |
| A09 | 删除完成后打开原会话结果卡 | 显示作品已删除及原成功制作信息，不显示资源损坏/推理失败、不自动补图，下一条输入不变。 |
| A10 | 查询、收藏、删除与查看器响应交错 | 旧响应不反向覆盖已确认收藏、不复活已删作品/会话；关闭相关查看器和一次性导航意图，选择及计数符合当前查询。 |

## 存储、互斥与中断恢复

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| S01 | 旧版本链及 v5 升级 v6，迁移故障注入 | ID、原始 JSON、图片、外键与活动选择保持；默认未收藏，失败完整回滚，不重建空库。 |
| S02 | 删除意图写入失败、会话事务提交前后终止 | 意图写入失败不删文件；会话事务要么原状要么完整删除，重放只产生一个后继。 |
| S03 | primary 删除后、mask 删除前、最终完成事务前强杀 | 重启恢复原已确认范围，缺失文件幂等，未完成状态可见，最终不残留登记产物、不复活作品。 |
| S04 | 模拟权限、Windows 只读和文件句柄占用 | 未完成卡片和原因可见，不提前成功；条件恢复后重试完成，不改变其他文件权限。 |
| S05 | 非法 ID、导入源图 ID、mask ID、任意/逃逸路径 | 不接受作为独立作品删除目标，不跟随逃逸链接，原件/外部导出/模型/其他作品保持。 |
| S06 | 与图片读取、原生导出及新源图引用并发 | 共享门禁串行裁决，不出现删除后继续成功读图、导出半文件或活动请求引用悬空。 |
| S07 | 删除原图后尝试旧历史重试 | 保存原来源事实；若重试需要该源图则明确要求重新选择，不从历史缓存假冒原资产。 |

## 集成回归与质量门

- 在原生应用执行至少一次真实文生图与一次真实去背景，核对普通/双输出图片；在原位验证发送、停止、清理后显式重试、查看、导出及接续输入。编辑和放大表单的可达性、输入保护和门禁也须验证，本次不重新承诺所有硬件或模型性能。
- macOS 与 Windows 分别保存界面和文件清理证据；无法访问的平台保持“未验收”，不以另一平台的 fixture 替代。模型未就绪、离线历史浏览、中文 IME、其他会话输入保护和强杀恢复按相关场景记录。
- 执行当前项目质量命令：`npm --prefix apps/frontend test`、`npm --prefix apps/frontend run check`、`npm --prefix apps/frontend run build`、`cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets --locked -- -D warnings`、`cargo test --workspace --locked`、`openspec validate --all --strict`。
- 本提案阶段只执行 `openspec validate simplify-workspace-and-manage-library --strict`、OpenSpec 全量 strict 与文档差异检查；不把未开始的实施任务标为完成。
