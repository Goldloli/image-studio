# Windows 全模型对齐验收计划

状态：待用户确认；Gate 0 可行性已部分实测（Qwen/MOSS 功能可行、内存预算未达标，见 verification/windows-parity-gate0）。本计划覆盖新增六个型号与 Windows 平台回归；每项记录 case ID、时间、平台、命令/原生操作、预期/实际、pass/fail/not_run/blocked、证据路径与资源数据。

## 通用规则

- 主认证设备仍为 Windows 10 22H2 / RTX 3080 Ti 12 GB / 32 GB RAM / i7-13700K。
- 每个新模型必须独立完成 Gate 0、安装、真实执行、取消/强杀、原生 UI 与证据；不得引用 macOS 或第一轮 Z-Image 结果冒充。
- 资源门槛：加载 ≤600 s、单次执行 ≤900 s、独占显存 ≤10.5 GiB 且无共享内存回退、进程 commit ≤24 GiB、可用 RAM ≥2 GiB；不达标时按 design 的硬件门槛或量化策略记录真实结果。
- 许可证与硬件门槛在模型页可见；低于门槛不得出现可执行入口。

| ID | 验证 | 通过条件 |
|---|---|---|
| G2-K1 | Klein 文生图/单图编辑加载与单次执行 | 固定快照与文件摘要；真实出图/编辑；资源与耗时入预算 |
| G2-B1 | BiRefNet ONNX CPU 加载与推理 | RGBA+mask 双输出；CPU provider；预算与时限 |
