## ADDED Requirements

### Requirement: Windows 目标机真实出图验收覆盖当前构建的能力矩阵与作品管理

Windows 目标机真实出图验收 SHALL 在当前构建上、在目标 Windows 10 x64 / RTX 3080 Ti 12 GiB 机器内，通过产品界面完成七个已接入型号、八项能力（Klein 文生图与单图编辑、Z-Image 文生图、Qwen-Image 2.1、Qwen-Image 2.1-Turbo、MOSS-Image-SFT、BiRefNet 去背景、Real-ESRGAN 4×）的真实输出；每项 SHALL 记录提示词、模型与执行身份、输出尺寸/字节/SHA-256 与阶段进度。验收 SHALL 使用本轮真实生成的作品验证当前构建的作品查询、筛选、收藏、预览、导出、受控删除、双输出删除、引用阻止/解除、会话删除与作品墓碑；并 SHALL 使用既有真实 v5 数据根的可丢弃副本验证 v5→v6 升级后的作品保留、查看与导出。构造 fixture 或旧文件副本 MUST NOT 被标注为本轮真实生成结果。

#### Scenario: 七型号八能力真实输出

- **WHEN** 执行当前构建的真实出图验收
- **THEN** 七个已接入型号各至少一次成功执行其登记能力，输出为产品内生成并提交的正式作品
- **AND** 每项记录输出尺寸、字节数、SHA-256、提示词、seed 与模型/执行身份
- **AND** 任何失败或未执行项保持 `fail`/`blocked`/`not_run`，不用其他型号或历史图片补位

#### Scenario: 真实新作品进入管理流程

- **WHEN** 本轮真实生成完成
- **THEN** 收藏、筛选、预览、导出、受控删除、双输出删除、引用阻止与解除、会话删除墓碑使用本轮生成的作品验证
- **AND** 导出文件与正式资产逐字节一致，删除后外部导出副本与旧作品历史保持
- **AND** 报告明确区分本轮真实作品与 v5 旧作品副本

#### Scenario: 真实 v5 数据升级

- **WHEN** 使用既有真实 v5 数据根的可丢弃副本以当前构建首次启动
- **THEN** 旧作品、任务、会话与草稿按规格保留并可查看/导出
- **AND** 升级后可重装至少一个型号并完成一次真实生成
- **AND** 迁移失败时不重建空库，无法安全构造的失败保护项记 `not_run`

### Requirement: Windows 目标机真实出图验收的证据口径与结论标签

真实出图验收 SHALL 记录每项能力的产品级证据：提示词与参数、模型与执行身份、输出尺寸/字节/SHA-256、阶段进度、加载与生成墙钟、导出校验；资源证据 SHALL 包含 host 观测的 GPU 使用峰值（注明采样间隔与桌面基线）、生成进程树私有提交峰值、可用物理内存最低值与对应阈值。worker 内部 CUDA reserved 未被产品持久化时，所述证据 MAY 由同一执行面的历史 Gate 0 记录承担，但 SHALL 显式标注"复用"及基线提交/路径；执行面发生变化时该复用无效，相关项 SHALL 记为 `not_run` 并另行认证。每项状态 SHALL 为 `pass`/`fail`/`blocked`/`not_run`；人工复核项 SHALL 记录操作者与结论；报告 MUST NOT 把复用证据、其他机器结果或功能回归写成当前构建的实测通过。

#### Scenario: 产品级资源采样

- **WHEN** 一次真实生成正在执行
- **THEN** 以固定间隔采样 GPU used、生成进程树私有提交与可用物理内存并保存原始 CSV
- **AND** 汇总 JSON 注明采样方法、桌面基线与阈值，不宣称达到 worker 内部精度

#### Scenario: 复用 Gate 0 资源口径

- **WHEN** 产品未持久化 worker CUDA reserved 且执行面 diff 审计为无变化
- **THEN** 引用历史 Gate 0 证据并标注复用，产品级预算用 host 观测口径对照
- **AND** 不把历史 Gate 0 数字写成当前构建的新实测

#### Scenario: 至少一条真实网络安装路径

- **WHEN** 本轮需要验证下载链路
- **THEN** 在空缓存根真实下载并安装至少一个小构件，记录 URL、耗时、校验和与代理环境
- **AND** 其余安装使用已验证种子缓存并标注 provenance
- **AND** 网络不可用或校验失败时记 `blocked`，不冒充安装或出图通过

#### Scenario: 人工复核与未执行项

- **WHEN** 视觉质量、真实 IME 或显示缩放依赖人工操作
- **THEN** 记录 `pending_user` 与操作者，机器检查单独记录
- **AND** 未执行项保持 `not_run`，不写成通过

## MODIFIED Requirements

### Requirement: Windows 12 GB 标准档在当前主分支上有真机回归证据

Windows 验收 SHALL 在目标 Windows 10 x64 / RTX 3080 Ti 12 GiB 真机上记录当前构建提交、安装包或可执行文件哈希、设备身份和验收档位，并审查当前构建相对既有生图基线是否改变执行面。功能回归完成当前构建的安装、原生界面和本地管理验证，不执行模型推理。完整生图认证 SHALL 在下列任一条件成立时执行：模型、运行时、worker、协议、计划/配方、设备门槛、安装量化或生成提交/恢复链发生变化；既有基线缺失、不完整或不可追溯；所有者明确要求在当前构建上执行完整真实出图验收。完整生图认证 SHALL 覆盖已安装的标准档能力至少各完成一次产品内真实生成、编辑、去背景或放大，记录 CUDA reserved（或按证据口径复用的等价证据）、private commit、可用物理内存最低值、加载/生成墙钟和导出逐字节一致性。未发生执行面变化、基线完整且所有者未要求重新认证时，功能回归 MAY 复用该目标机生图证据，但不得把它改记为当前构建的新实测；其他机器（含 8 GB 补充机）的功能回归、历史生图基线与 CI 结果 MUST NOT 替代目标机当前构建的完整生图认证。

#### Scenario: 仅界面和本地管理变化

- **WHEN** 当前构建相对完整生图基线没有执行面变化，且既有证据绑定目标机、模型/运行时身份和结果文件，所有者也没有要求重新认证
- **THEN** 当前构建可以在完成 Windows 功能回归后声明功能验收通过
- **AND** 报告引用既有生图基线，不下载模型、不运行推理、不生成新图片，也不声称重新完成生图认证

#### Scenario: 所有者要求当前构建的真实出图验收

- **WHEN** 所有者明确要求在当前构建上执行包含真实出图的完整验收，即使 diff 分类为无执行面变化
- **THEN** 在目标 Windows 10 / RTX 3080 Ti 12 GiB 机器上执行完整真实出图验收，覆盖七个型号、八项能力、当前构建的作品/会话管理与真实 v5 数据升级
- **AND** 不得以 8 GB 补充机的功能回归、历史生图基线或 CI 结果替代本轮结果，未执行项保持 `not_run`

#### Scenario: 执行面发生变化

- **WHEN** 当前构建改变模型、运行时、worker、协议、计划/配方、设备门槛、安装量化或生成提交/恢复行为
- **THEN** 必须执行目标机完整生图认证，覆盖受影响的标准档能力并记录原资源、时限、取消/恢复与导出口径
- **AND** 功能回归通过不能替代该认证，未执行项保持 `not_run`

#### Scenario: 基线缺失或差异无法分类

- **WHEN** 找不到完整目标机生图基线，或无法确定 diff 是否改变执行面
- **THEN** 默认要求完整生图认证，不以"可能不受影响"的推断关闭验证

#### Scenario: 证据身份与结论标签

- **WHEN** 验收报告同时引用当前功能回归和历史生图认证
- **THEN** 分别记录当前提交/安装包哈希与历史基线提交/证据路径，并分别标注"功能回归通过"和"生图基线复用"
- **AND** 不得把两类结果合并成"当前构建全部重新认证通过"

#### Scenario: 档位投影与设备身份

- **WHEN** 在完整生图认证要求生效的当前构建上打开模型页
- **THEN** 设备身份显示 RTX 3080 Ti / 约 12,288 MiB / sm86
- **AND** 已安装型号显示 `standard · 1024² · bfloat16`，不出现紧凑档投影
- **AND** Z-Image Turbo 按 12 GB 门槛显示为满足（若已安装则可执行）

#### Scenario: 标准档生成与资源口径

- **WHEN** 完整生图认证要求对已安装的标准档能力发起产品内真实执行
- **THEN** 记录输出 PNG 的尺寸、字节数与 SHA-256，以及 CUDA reserved（或按复用口径标注的等价证据）、进程 commit、可用内存最低值和墙钟耗时
- **AND** 资源口径逐项对照标准档合同（CUDA reserved ≤10.5 GiB、private commit ≤24 GiB、可用物理内存最低 ≥2 GiB、加载 ≤600 s、生成 ≤900 s、无 WDDM 共享内存回退）

#### Scenario: 种子缓存重装与重启恢复

- **WHEN** 完整生图认证要求因激活身份变化拒绝旧就绪记录，随后使用已验证的本地种子缓存重装
- **THEN** 安装记录标注为种子缓存类型并完整记录阶段与耗时，不宣称验证了下载链路
- **AND** 重装后可完成一次标准档生成，导出文件与资产逐字节一致
- **AND** 重启应用后型号仍为就绪，旧作品可重开

#### Scenario: 安装期量化准备被内存预检阻止

- **WHEN** 完整生图认证需要安装量化准备，而本机可用物理内存低于 8 GiB 或 commit 余量低于 6 GiB
- **THEN** 安装器在开始量化前以包含实测值与可行建议的中文错误失败
- **AND** 不留下部分 prepared 缓存或安装记录，且该事件以 `blocked` 记录，不得改写为通过
