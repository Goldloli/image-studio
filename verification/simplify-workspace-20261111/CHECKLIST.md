## 1. 准备

- 已构建 dev 包：`target/dev/Image Studio.app`（debug，内嵌当前前端生产构建）。
- 使用**真实数据根**才能做真实生成验收（模型安装位于数据根内）；默认数据根：
  `~/Library/Application Support/ImageStudio`。
- **数据安全**：新构建首次启动会把 SQLite v5 升级到 v6（不可被旧构建识别）。启动前关闭应用并备份：
  ```bash
  cd "$HOME/Library/Application Support/ImageStudio"
  cp -p library.sqlite3 library.sqlite3.v5-backup
  [ -f library.sqlite3-wal ] && cp -p library.sqlite3-wal library.sqlite3-wal.v5-backup || true
  [ -f library.sqlite3-shm ] && cp -p library.sqlite3-shm library.sqlite3-shm.v5-backup || true
  ```
  回退：关闭应用，把备份复制回原名（仅在使用旧构建时）。
- 启动：`open "target/dev/Image Studio.app"`（若 Gatekeeper 拦截，右键 → 打开）。
- 若只想先验证界面而不动真实库，可用隔离根：
  `"target/dev/Image Studio.app/Contents/MacOS/image-studio-desktop" --data-dir /tmp/image-studio-accept`
  但隔离根没有模型，真实生成项会显示“未就绪”，此时只记录界面项。

### B. 会话管理（C01–C07）

- [ ] C01 悬停或键盘聚焦任意会话行（含长标题）：同时出现“重命名/删除”，可独立命中，不误切会话。
- [ ] C02 打开删除确认后取消或 Escape：会话、输入、作品、收藏不变，焦点回到原行操作。
- [ ] C03 删除非当前空闲会话：当前会话输入/参数/阅读位置不变；重启后不复活。
- [ ] C04 删除当前会话：自动选中最近活动会话并恢复其草稿；删除最后一个会话时只出现一个默认空会话。
- [ ] C05 在目标会话正在生成/取消/清理时点删除：被拒绝并提示先停止等待清理；另一空闲会话仍可删除。
- [ ] C06 目标草稿在确认前后发生变化时（另一窗口/快速编辑后立即确认）：确认被刷新或拒绝，不丢新输入；重复点击不产生第二个替代会话。
- [ ] C07 删除有作品的会话：作品、收藏、原图/蒙版与制作记录保留；来源显示原标题与“会话已删除”，返回会话不可用。

### C. 作品管理（A01–A10）

- [ ] A01 网格与列表中每张作品右下角有收藏/删除按钮，键盘可聚焦，点击不打开预览、不误触另一按钮。
- [ ] A02 收藏、取消收藏后重启：状态保持；保存失败显示未保存且不保留虚假值。
- [ ] A03 在“仅收藏”下能查到较早（非当前页）的收藏作品，总数正确，分页无重复/跳项。
- [ ] A04 “仅收藏”与日期/型号/尺寸/会话取交集；清除条件恢复全部。
- [ ] A05 区分“尚无收藏作品 / 当前条件无结果 / 尚无作品 / 读取失败”，各提供对应清除或重试入口。

- [ ] A07 删除去背景作品时主图与蒙版一起删除；输入源图与其他派生作品保持；旧 ID 不可再预览/导出/作源图。
- [ ] A08 作品正被未删除会话的草稿或活动请求当作源图时：拒绝删除并指出关联会话；解除后可删。
- [ ] A09 删除完成后回到原会话卡：显示“作品已删除”，保留原制作记录，不显示资源损坏或自动补图。
- [ ] A10 快速切换筛选、收藏、删除、打开/关闭预览交错操作：旧响应不覆盖新收藏、不复活已删作品/会话。
