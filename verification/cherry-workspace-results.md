## 离线与干净源码验证

[独立源码构建](cherry-clean-source-build.json) 在拷贝后、生成前记录 52 份源文件哈希，排除 node_modules/dist/gen/autogenerated，再运行离线 npm ci、前端 build 与 cargo workspace build。三个阶段均退出 0，报告显示 workspace_sources_changed_since_copy=[]。复用 npm/Cargo 缓存和 target/clean-validation，不称冷构建，也不称 Git checkout。

[禁止联网启动](cherry-offline-startup.json) 仅给测试进程施加 sandbox profile。网络对照 curl 失败，Tauri 主 WebView PageLoadEvent::Finished 后输出 ready，进程存活且无模型/诊断 worker。正常原生 CUA 另外确认图片和交互；不声称在该 sandbox 子进程中重跑了全部 UI 矩阵。

## 安全边界与已知差异

前端仅有工作区状态与显式诊断命令，无通用文件、Shell、HTTP 插件权限；worker 路径和工作目录在 Rust 侧持有，模式使用白名单。日志和快照有界，React 将用户提示词作为文本显示。本地 CSP 不允许远程脚本与框架页面。

与参照的差异是本产品名称和原创素材、非透明表面、默认展开 composer、有限页面/草稿标签、功能保持真实空态。未做 Cherry 的标签拖出新窗、聊天、知识库、供应商配置和复杂自动收起时序；未引入真实推理、持久化或图片导出。
